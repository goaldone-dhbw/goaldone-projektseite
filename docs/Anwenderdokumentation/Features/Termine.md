# Termine

## Überblick

GoalDone verwendet Termine als feste Zeitblocker für die automatische Planung. In diesen Zeiträumen werden keine flexiblen Aufgaben eingeplant.

Termine eignen sich zum Beispiel für:

* Arzttermine
* Telefonate
* Meetings
* Vorlesungen
* regelmäßig wiederkehrende Termine wie ein Daily

## Termine verwalten

In der Terminübersicht werden alle festen Termine angezeigt. Jeder Termin ist einer Organisation oder einem Verein zugeordnet.

Ein Termin besteht mindestens aus:

* Unternehmen / Verein
* Titel
* Art des Termins
* Datum oder Zeitraum
* Startzeit
* Endzeit

## Termin hinzufügen

### Einmaligen Termin erfassen

Ein einmaliger Termin gilt nur für ein bestimmtes Datum.

1. Navigieren Sie im Menü zu **Termine**.
2. Klicken Sie auf **Termin hinzufügen**.
3. Wählen Sie das passende **Unternehmen** oder den passenden **Verein** aus.
4. Geben Sie einen **Titel** ein, z. B. „Arzttermin“.
5. Wählen Sie bei **Art** die Option **Einmalig**.
6. Geben Sie das gewünschte **Datum** ein.
7. Legen Sie **Startzeit** und **Endzeit** fest.
8. Speichern Sie den Termin.

Der Termin wird anschließend in der Übersicht angezeigt und bei der automatischen Planung als blockierter Zeitraum berücksichtigt.

## Wiederkehrende Termine

Wiederkehrende Termine gelten nicht nur für ein einzelnes Datum, sondern wiederholen sich an ausgewählten Wochentagen innerhalb eines bestimmten Zeitraums.

Sie eignen sich zum Beispiel für:

* tägliche oder wöchentliche Meetings
* regelmäßige Dailys
* Vorlesungen
* Sporttermine
* feste private Verpflichtungen

### Wiederkehrenden Termin erfassen

1. Navigieren Sie im Menü zu **Termine**.
2. Klicken Sie auf **Termin hinzufügen**.
3. Wählen Sie das passende **Unternehmen** oder den passenden **Verein** aus.
4. Geben Sie einen **Titel** ein.
5. Wählen Sie bei **Art** die Option **Wiederkehrend**.
6. Geben Sie ein **Startdatum** ein.
7. Geben Sie optional ein **Enddatum** ein.
8. Wählen Sie die gewünschten **Wochentage** aus.
9. Legen Sie **Startzeit** und **Endzeit** fest.
10. Speichern Sie den Termin.

## Varianten bei wiederkehrenden Terminen

Wiederkehrende Termine können aus mehreren Varianten bestehen. Eine Variante beschreibt einen bestimmten Zeitraum mit eigenen Wochentagen und Zeiten.

Das ist hilfreich, wenn ein regelmäßiger Termin nicht über den gesamten Zeitraum gleich bleibt.

Beispiel:

* Ein Daily findet zunächst von Montag bis Donnerstag statt.
* Ab einem späteren Datum findet es zusätzlich am Freitag statt.
* Danach gilt wieder eine andere Wochentagsauswahl.

In diesem Fall zeigt GoalDone den wiederkehrenden Termin in der Übersicht zusammengefasst an und weist mit einem Hinweis wie **„3 Varianten“** darauf hin, dass mehrere Varianten existieren.

### Varianten anzeigen

1. Öffnen Sie die Terminübersicht.
2. Suchen Sie den wiederkehrenden Termin.
3. Klicken Sie auf **Varianten anzeigen**.
4. Die einzelnen Varianten werden unter dem Termin eingeblendet.

Für jede Variante wird angezeigt:

* ob es sich um einen wiederkehrenden Termin handelt
* die betroffenen Wochentage
* das Startdatum
* falls vorhanden das Enddatum
* die Start- und Endzeit

Über **Varianten ausblenden** können die Varianten wieder eingeklappt werden.
Die Varianten werden durch das Bearbeiten in der Planungsansicht erstellt.

## Termin bearbeiten

Ein bestehender Termin kann über das Bearbeiten-Symbol geändert werden.

Dabei können je nach Terminart angepasst werden:

* Titel
* Organisation oder Verein
* Datum oder Zeitraum
* Wochentage
* Startzeit
* Endzeit

Bei wiederkehrenden Terminen können einzelne Varianten bearbeitet werden, damit Änderungen gezielt für bestimmte Zeiträume gelten.

## Termin löschen

Ein Termin kann über das Löschen-Symbol entfernt werden.

Nach dem Löschen wird der entsprechende Zeitraum nicht mehr als fester Blocker in der Planung berücksichtigt.

## Bedeutung für die Planung

Termine gelten in GoalDone als feste Blocker. Die automatische Planung darf flexible Aufgaben nicht in Zeiträume legen, die bereits durch Termine belegt sind.

Das bedeutet:

* Einmalige Termine blockieren genau den angegebenen Zeitraum an einem bestimmten Datum.
* Wiederkehrende Termine blockieren die angegebenen Zeiträume an den ausgewählten Wochentagen.
* Varianten wiederkehrender Termine ermöglichen unterschiedliche Regeln für verschiedene Zeitabschnitte.

Dadurch kann GoalDone Aufgaben realistischer planen und feste Verpflichtungen berücksichtigen.
